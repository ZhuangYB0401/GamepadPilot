# GamepadPilot（手柄领航）

GamepadPilot 是一个面向 Windows 10/11 的 Xbox/XInput 手柄桌面控制工具。它可以把手柄按键和摇杆映射为键盘、鼠标、媒体键、浏览器键和宏，并通过图形界面自定义。程序关闭主窗口后继续驻留托盘。

## 主要功能

- 支持 Xbox 及 XInput 兼容手柄，轮询频率 125 Hz，支持热插拔。
- 支持 A/B/X/Y、方向键、LB/RB、LT/RT、Back/Start、L3/R3、左右摇杆和组合按键。
- 支持单击、按住、长按、双击、连续摇杆动作和组合触发。
- 动作可映射到键盘组合、鼠标移动、鼠标左右中键、双击、滚轮、媒体键、浏览器键及系统键。
- 宏可录制键盘、鼠标按钮和滚轮，也可在界面中编辑步骤、延迟、速度和循环方式。
- 多套配置、手动切换和按进程名/窗口标题自动切换。
- 全屏模式不再自动暂停；B 键保留为发送 Esc 的全屏退出快捷键。
- 托盘驻留、全局热键、开机自启、JSON 导入导出。
- 无网络功能、无遥测，不需要安装驱动。

## 系统要求

- Windows 10 22H2 或 Windows 11，64 位。
- Xbox 或 XInput 兼容手柄。
- 便携版不需要单独安装 .NET 运行时。

## 直接运行

发布后运行 `artifacts/publish/GamepadPilot.exe`。第一次启动会显示主窗口；关闭窗口后会静默隐藏到系统托盘，不再弹出提示。要完全退出，请使用托盘菜单中的“退出”。

默认桌面预设：

| 手柄输入 | 动作 |
| --- | --- |
| 左摇杆 | 移动鼠标 |
| 右摇杆 | 垂直/水平滚动；向上滚动页面上方 |
| A / B | 按住鼠标左键 / 右键 |
| X / Y | 按住 Enter / Esc |
| 方向键 | 对应方向键 |
| LB / RB | 浏览器后退 / 前进 |
| LT / RT | Page Up / Page Down |
| 背键 1–4 | 默认空白；是否可用取决于手柄驱动是否单独上报 |
| L3 / R3 | 开始菜单 / 任务视图 |
| Back / Start | Backspace / Enter |

浏览器预设会在 Google Chrome（`chrome.exe`）或 Microsoft Edge（`msedge.exe`）位于前台时自动启用：

| 手柄输入 | 动作 |
| --- | --- |
| LB / RB | 鼠标侧键 1（后退）/ 鼠标侧键 2（前进） |
| LT / RT | 按住后线性降低 / 提高系统音量 |
| A/B/X/Y 和摇杆 | 与桌面预设一致 |

默认全局热键：

- `Ctrl+Alt+F12`：启用或暂停全部映射。
- `Ctrl+Alt+End`：紧急停止映射。
- `Ctrl+Alt+F11`：打开主窗口。
- `Ctrl+Alt+F10`：停止宏录制。

## 鼠标手感优化

- 手柄轮询周期为 4 ms（最高约 250 Hz），并在手柄服务运行期间启用 1 ms Windows 定时器精度。
- 鼠标位移保留不足 1 像素的小数部分，不再因逐帧取整而丢失低速移动。
- 鼠标移动事件使用“禁止合并”标志，降低系统合并高刷新位移造成的顿挫。
- 默认左摇杆采用线性曲线、1500 像素/秒灵敏度和低平滑，设置页可进一步调整死区、灵敏度、平滑和曲线。

手柄回传率仍可能低于游戏鼠标的 1000 Hz；如果手柄驱动本身只有约 125 Hz 上报率，体感无法完全等同于高端游戏鼠标。

## 打字轮盘

- 默认按下 L3 开启或关闭打字轮盘，开关按键可在设置页更改。
- 开启后，屏幕中心会出现透明八边形轮盘，中央为无文字、上下边水平且方向与外侧一致的正八边形，内部完全透明。
- 左摇杆或十字键用于选择八个方向；每个区块四个字符按实体手柄布局排列。
- 颜色对应按键：底部绿色 A、右侧红色 B、左侧蓝色 X、顶部黄色 Y；界面不显示额外的 A/B/X/Y 标签。只有当前选中区块的圆形按钮显示彩色底和白色字符，其他区块保留白色字符并隐藏按钮底色。
- 右摇杆向左/向右切换层级；第一层为字母及逗号、句号、问号、斜杠、减号、等号，第二层为数字和符号。
- LB 为空格，RB 为退格，RT 为回车；LT 按住时作为 Shift，实时切换大写字母和符号输入。
- 开启轮盘时普通手柄映射暂停，关闭后自动恢复。
- 侧边栏“使用说明”页包含完整的按键提示和使用步骤。轮盘外观已回滚为 v1.6.1 样式。

## 使用说明

1. 连接手柄，在“总览”页确认连接状态。
2. 在“按键与摇杆”页选择配置和手柄输入，再设置触发方式及动作。
3. 键盘动作的输入框获得焦点后直接按键盘组合键即可捕获。
4. 在“宏”页新建宏，点击“录制实际输入”后离开程序窗口执行需要录制的操作，按 `Ctrl+Alt+F10` 停止。
5. 在“配置与自动规则”页为进程或窗口标题设置自动切换规则。
6. 在“设置”页调整摇杆参数、全屏暂停、开机启动和全局热键。

程序检测到全屏程序、配置窗口获得焦点、宏正在录制或用户手动暂停时，会停止映射并释放已按下的模拟按键。旧版配置会安全迁移：只修改仍保持旧默认值的桌面预设，不会覆盖自定义配置，会自动恢复桌面预设的 LB/RB/LT/RT，并添加浏览器预设和 Chrome/Edge 切换规则。普通权限无法向管理员程序发送模拟输入；如有需要，可右键选择“以管理员身份运行”，但开机启动不会自动提权。

配置文件保存在 `%APPDATA%\GamepadPilot\config.json`，日志保存在 `%LOCALAPPDATA%\GamepadPilot\logs`。可在设置页直接导入或导出配置。

## 构建

在本机执行：

```powershell
./build.ps1 -Configuration Release -Publish
```

脚本会在缺少 SDK 时把 .NET 10 SDK 安装到项目本地 `.tools` 目录，执行还原、编译和自检，然后生成：

```text
artifacts/publish/GamepadPilot.exe
```

如需跳过自检：

```powershell
./build.ps1 -SkipTests -Publish
```

## 项目结构

- `src/GamepadPilot.Core`：配置模型、映射引擎、宏执行和纯逻辑测试接口。
- `src/GamepadPilot.App`：WPF 界面及 Windows/XInput/SendInput/托盘平台层。
- `tests/GamepadPilot.SelfTest`：不依赖第三方测试框架的自检程序。

## 已知边界

- 只支持 Xbox/XInput 兼容设备，暂不支持 DualSense、DualShock 和 DirectInput 专用模式。
- 标准 XInput 不暴露厂商背键；背键 1–4 已提供配置入口，但需要手柄驱动或厂商工具将背键作为扩展 XInput 按键上报后才会触发。
- 不会屏蔽手柄在游戏中的原始输入；全屏时默认暂停桌面映射以避免冲突。
- 宏只能模拟键盘和鼠标输入，不执行程序、网址、PowerShell 或 CMD 命令。
- 当前发布文件未进行商业代码签名，Windows SmartScreen 可能显示未知发布者提示。
